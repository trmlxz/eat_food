# 小肚子雷达 · Little Tummy Lab

适合手机使用的儿童食物探索单页面应用。React + TypeScript + Vite，纯静态部署，无后端、账号或照片上传。

## 本地使用

需要 Node.js 24 和 npm。

```sh
npm ci
npm run dev
```

访问终端给出的本地地址。同一 Wi-Fi 下的手机可访问终端中的 Network 地址。点击“开始”进入黑色全屏扫描界面，再点击“开始扫描”，约 4 秒旋转三圈后显示胃部。界面仅保留雷达/胃部、扫描按钮与退出入口；横屏时按钮放在右侧。点击左上角关闭按钮或按 Escape 返回，进行中的扫描会取消。全屏采用浏览器可用视口（100dvh），手机浏览器自身地址栏由系统控制。双击右上角“家长设置”打开菜单，电脑也可聚焦该按钮后按 Enter。

六档大小：蓝莓、草莓、小枣、鸡蛋、苹果、大苹果。默认第 4 档，胃内默认无食物，必须在菜单中显式选择。新增照片只加入素材库，不会自动选中。支持多选、结果预览、可选音效；默认静音。音效是长短交替的“滴嘟”提示音，12 声分成四组、音高沿五声音阶逐组上行，组内密集、组间留白，最后一组之后留约 0.74 秒空档，再落下一声清脆的钟形“叮”。全部由 Web Audio 实时合成，无音频文件。系统开启减少动态效果时，扫描缩短至 600 毫秒，音效同步换成两声加完成提示音。

家长菜单“想吃什么”可单选一种内置食物或自己的食物照片，在胃部图片右上角显示装着该食物的思考气泡，表示“小肚子想吃它”。与胃内已有食物独立设置，不会自动把食物放进胃里。默认不显示，可随时选择“不显示气泡”关闭。气泡与胃部一起缩放、拖动，不参与蠕动变形；支持结果预览、普通设置保存和调试模式即时修改。删除对应的食物照片会同时清除气泡选择。

家长菜单“更多设置”可选择哭泣（带眼泪）、不高兴（无眼泪）、微笑、大笑四种表情，默认微笑，支持实时预览与保存；同时提供胃部蠕动开关，以及独立的速度、幅度 1～5 级调节，附实时预览。默认关闭、速度 3 级、幅度 2 级；保存后作用于扫描结果并在刷新后保留。速度从每周期 6 秒到 1.2 秒，幅度从轻微到明显。旧版本设置自动补全默认值。系统开启减少动态效果时暂停蠕动。

胃部六档按可用显示区域的线性尺寸设置为约 36%、54%、75%、100%、150%、220%，保持轮廓比例并为蠕动留出边缘空间；鸡蛋相当于旧版大苹果；大苹果超出视口，屏幕仅容纳部分胃部，可拖动查看。

本次升级清空一次旧版本的食物选择（旧数据无法区分自动选择和手动选择），保留其他设置与照片。重新显式选择并保存后会持续保留。

## 照片与数据

“食物朋友”中可拍照或从图库选择，拖动、缩放裁剪后输入名称保存。图片本地生成 768 × 768 JPEG，胃内食物的渐变透明边缘由 SVG 遮罩处理，并统一裁切在胃内；思考气泡中的食物单独显示，不受胃内遮罩影响。照片不会自动去背景。单张输入上限 25 MB；浏览器无法解码的格式会提示转换。

设置保存在 localStorage，照片保存在 IndexedDB。照片保存/删除立即作用于素材库；普通家长菜单中的食物选择和等级需要点击“保存设置”，调试浮层中的修改即时生效并自动保存。清理浏览器数据会删除照片，不同域名、端口、浏览器及设备的数据不互通。图库删除无法撤销。

这是家长预设的趣味模拟，不测量真实胃部，也不提供健康判断。

## GitHub Pages 发布

1. 在 GitHub 新建一个空仓库。
2. 将本地仓库关联并推送（替换下面的地址）：

```sh
git remote add origin https://github.com/YOUR_NAME/YOUR_REPO.git
git push -u origin main
```

3. 打开仓库 **Settings → Pages → Build and deployment → Source**，选择 **GitHub Actions**。
4. 工作流 `.github/workflows/deploy.yml` 自动测试、构建并部署；必要时在 Actions 中手动运行 “Deploy to GitHub Pages”。
5. 完成后，Pages 设置和工作流会显示网站地址，通常为 `https://YOUR_NAME.github.io/YOUR_REPO/`。

Vite 使用相对资源路径 `base: './'`，没有路径路由，支持仓库子目录部署；请使用带结尾 `/` 的网站根地址。工作流参考 [Vite 官方静态部署文档](https://vite.dev/guide/static-deploy.html#github-pages)。当前仅初始化本地仓库，未创建 GitHub 远程仓库或实际上线。

## 检查

```sh
npm test
npm run build
npm run preview
```

自动测试覆盖扫描状态、重复扫描、设置保存/取消、预览、损坏数据与存储失败、照片库增删与重新读取。生产构建先执行 TypeScript 检查。页面内使用 SVG/CSS 与系统 Emoji，无外部字体或素材服务依赖，Emoji 外观随系统不同。

布局含 320px 小屏、手机、横屏和桌面断点。已在 Wework 内置浏览器验证桌面扫描与结果；真实 iOS Safari / Android Chrome 的相机调用、照片裁剪手势及手机布局仍需设备验收。`capture="environment"` 是系统提示，具体选图菜单由设备决定；GitHub Pages 的 HTTPS 地址适合最终验收。

扫描结果使用覆盖整个浏览器视口的独立显示层，支持单指或鼠标拖动胃部位置，不支持捏合、滚轮或拖拽缩放。胃部可显示至屏幕四边，仅在屏幕边界裁切，不受原雷达框和按钮区域限制。位置移动包含胃部轮廓、食物和遮罩；蠕动保持原设置。拖动范围保留胃部可见部分，重新扫描后居中。退出、扫描和调试入口浮在图像上方。

“家长设置 → 更多设置 → 调试模式”默认关闭，开启并保存后，雷达页右上角出现“选项”。点击打开非模态浮层，可即时调整大小、食物、表情、蠕动和音效并自动保存，背景胃部仍可拖动。打开浮层会停止当前扫描并直接显示胃部用于调试；修改不会重置拖动位置。关闭浮层不会重新扫描或撤销修改。按 Escape 优先关闭浮层，再按一次退出扫描界面。关闭调试开关会收起浮层并隐藏入口；存储失败时保持本次效果并明确提示未保存。

首页与设置采用紧凑布局，照片每页 3 张，点击翻页；结果预览替换当前设置内容，收起后返回。极矮屏幕、放大字体或弹出键盘时保留必要的滚动，以免控件无法访问。
